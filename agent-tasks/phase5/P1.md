# P1 — JSON Schema + Model POCOs + Validator

**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §1, §2, §3 (all), §7.4 → this file. Apply with no discussion.

## What
Implement the generation vocabulary's semantic core:
- C# POCOs for: design tokens (§3.1), container tree + layout props (§3.2), rendering primitives Tier 1 + linear gradient (§3.3), size constraints (`.fixed/.grow/.aspect/.alignSelf`), overflow policy (`error|shrink|clip`), the document root (§3.4: version, design, slides).
- System.Text.Json deserialization of the JSON vocabulary.
- A **validator** with loud, actionable errors: JSON path + suggestion ("unknown property 'lable'. Did you mean 'label'?"). Reject CSS-isms (`flex-wrap`, `z-index`, percentages, `wrap`) explicitly.
- The JSON Schema document itself (the contract handed to structured-outputs consumers).

## Why
P1 is the contract every other workstream compiles against. It merges first; quality here unblocks everything.

- `PptxEditor.Core/Generation/Model/`

- `DocxEditor.Tests/Generation/` (new test folder)

## Depends on
- Nothing. .NET 9, System.Text.Json. Follow existing project conventions (nullable on, custom exceptions for domain errors).

## Acceptance
- The sample document in plan.md §3.4 deserializes and validates clean.
- Validator rejects ≥20 adversarial docs with actionable errors — including CSS-isms (`flex-wrap`, `z-index`, `"100%"`, `wrap`) and typos with near-match suggestions. This seeds plan §7.4.
- Colors referenced by palette token name; raw hex accepted but produces a warning (off-token drift, §3.1).
- `dotnet test` green; zero build warnings in owned files.
- Report per SHARED.md contract.
