# P7 — Parity Harness (fixtures + visual-diff + baselines)

**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §5, §2 (rule #2), §7.2 → `tools/visual-diff/` (existing suite) → this file. Apply with no discussion.

## What
Build the parity harness:
- Fixture generator: one generated deck per primitive — rect radii matrix, gradient angles/stops, text anchors, image fit modes, etc.
- Visual-diff integration: render each fixture via PowerPoint-PDF (ground truth) and Typst-SVG; compute RMSE per fixture against committed baselines; per-primitive thresholds.
- Wire generated-deck fixtures into the existing visual-diff suite alongside the REF smoke decks.

## Why
"Untested parity = primitive does not exist" (rule #2). The Typst render is the spec of record: OOXML is matched TO the preview.

## Owns (strict — nothing else)
- `tools/visual-diff/` (extend, don't rewrite)
- `PptxEditor.Core/Generation/Fixtures/`

## Depends on
- **P4 + P5 merged** (both emitters).

## Acceptance
- Every Tier-1 primitive + linear gradient has a fixture, an RMSE threshold, and a committed baseline.
- Suite runs via the existing visual-diff entry point and fails loudly on threshold breach.
- `dotnet test` green; existing REF smoke baselines untouched unless a regeneration is explicitly flagged in your report.
- Report per SHARED.md contract.
