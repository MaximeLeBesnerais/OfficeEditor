# P5 — Typst Emitter (#place-only)

**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §2, §3.3, §5 → `agent-instructions/AGENTS.typst.md` → this file. Apply with no discussion.

## What
Implement the Typst emitter: absolute draw tree → Typst source using **only** `#place` + absolute boxes. Typst does NO layout (no grid/align of its own — parity cost would double). Primitives: `text` (box + anchor + align + insets), `rect` (per-corner radius via `rect(radius: (top-left: …))`), `line`, `ellipse`, `image` (fit modes fill/crop/contain), `group`, `gradient` (`gradient.linear`: multi-stop, angle, alpha), shadow via faked offset rect.

## Why
This is the exact-preview path (PNG/SVG via TypstBridge) and the spec of record for parity (§5).

- Snapshot/golden tests on emitted Typst source per primitive (deterministic output).
- Radius mapping `round1Rect` OOXML ↔ Typst per-corner radius matches P4's semantics (coordinate via integration patch if a shared mapping table is needed — do NOT edit P4's files).
