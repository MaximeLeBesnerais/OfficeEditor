# P2 — LayoutResolver Core

**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §2, §3.2, §5 → this file. Apply with no discussion.

## What
Implement `LayoutResolver`: a **pure** module mapping (container tree + design tokens + font metrics) → absolute draw tree where every element has x, y, w, h in pt and resolved fills/fonts. Cover: `.row/.column/.grid`, `.justify` (all 5 modes), `.align`, `.padding` (all 3 forms), child constraints `.fixed/.grow(n)/.aspect/.alignSelf`, `.at(x,y)` escape hatch on layout-less containers, per-container overflow policy plumbing (`error` path fully; `shrink` delegates to P3's seam).

## Why
Layout is resolved exactly once, in C# (load-bearing rule #1). Both emitters (P4/P5) consume only your absolute draw tree.
