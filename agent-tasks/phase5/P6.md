**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §4, §3.1 (tokens), §3.2 (overflow contracts) → this file. Apply with no discussion.

## What
Implement the v1 component set (max 8): `card`, `kpi`, `title_block`, `bullet_list`, `divider`, `badge`, `image_card`, `table_block` (delegates to existing table emission). Components are C# functions over primitives — **NOT** a second layout system. Each has a token-driven style and an explicit overflow contract.

## Why
Components are the vocabulary the AI actually authors with; they give the "beautiful by default" quality bar.

- Unit tests: each component expands to the expected primitive subtree; overflow contracts honored.
- `dotnet test` green. Report per SHARED.md contract.
