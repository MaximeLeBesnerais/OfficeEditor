# P3 — Text Measurement Integration (overflow: shrink/error)

**Read first, in order:** `agent-tasks/phase5/SHARED.md` → `plan.md` §3.2, §5, §7.5 → this file. Apply with no discussion.

## What
Implement `TextMeasure.cs`: real font-metric text measurement wired into LayoutResolver's overflow seam. `overflow: shrink` uses the existing TextFitService (fontScale ≥ MinScale, else warning); `overflow: error` raises a loud domain error with the offending element path; `clip` passes through with a warning. Text-bearing leaves default to `shrink`; layout containers default to `error`.

## Why
"Overflow is an error/warning, never a reflow" is a core v1 promise (§1, §7.5). Silent clipping is a defect.

## Owns (strict — nothing else)
- `PptxEditor.Core/Generation/Layout/TextMeasure.cs`
- `DocxEditor.Tests/Generation/Layout/TextMeasureTests.cs`

## Depends on
- **P2 merged** (the seam/interface it defined).
- F6/TextFitService — already in the codebase (`PptxEditor.Core`); locate and reuse it. Do NOT reimplement wrap simulation or normAutofit emulation.

## Acceptance
- Golden tests with real font metrics: shrink path (scale applied, ≥ MinScale), MinScale violation → warning, error path → actionable exception.
- A deliberately oversized text in a fixed box shrinks or errors loudly — never silently clips (mirrors §7.5).
- `dotnet test` green. Report per SHARED.md contract.
