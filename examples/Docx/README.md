# DOCX Examples

This folder contains examples for creating and editing Word documents (.docx).

## Examples

### 1. Basic Document Creation
Create a simple document with headings, paragraphs, and formatting.

### 2. Markdown Conversion
Convert a Markdown file to a formatted Word document.

### 3. JSON Instructions
Use JSON/YAML instructions to declaratively manipulate documents.

### 4. Variable Detection
Find `{{variables}}` in templates.

### 5. Template Processing
Use conditionals and loops in templates.

## Running Examples

```bash
cd examples/Docx
dotnet run
```

Output files are saved to `examples/output/docx/`.
