# DOCX Examples

Every example shows **what you start with → the code you run → what you get**.

---

## 1. Basic Document Creation

**Input:** None (created from scratch)

**Code:**
```csharp
using var builder = DocumentBuilder.Create("01-basic.docx");

builder.AddParagraph("Welcome to OfficeEditor", "Heading1");
builder.AddParagraph("This document was created using the fluent C# API.");
builder.AddParagraph("You can easily add formatted text and paragraphs.");

builder.AddParagraph("Features:", "Heading2");
builder.AddParagraph("• Fluent API");
builder.AddParagraph("• Markdown support");
builder.AddParagraph("• JSON instructions");
builder.AddParagraph("• Variable replacement");

builder.AddParagraph("Getting Started:", "Heading2");
builder.AddParagraph("1. Install the NuGet package");
builder.AddParagraph("2. Create a DocumentBuilder");
builder.AddParagraph("3. Add content");
builder.AddParagraph("4. Save");

builder.Save();
```

**Output:** `output/docx/01-basic.docx`

```
Welcome to OfficeEditor
This document was created using the fluent C# API.
You can easily add formatted text and paragraphs.
Features:
• Fluent API
• Markdown support
• JSON instructions
• Variable replacement
Getting Started:
1. Install the NuGet package
2. Create a DocumentBuilder
3. Add content
4. Save
```

## 3. Variable Detection

**Input:** Template with variables

```csharp
using var builder = DocumentBuilder.Create("03-detection-template.docx");
builder.AddParagraph("Invoice for {{customerName}}");
builder.AddParagraph("Order #: {{orderNumber}}");
builder.AddParagraph("Total: ${{totalAmount}}");
builder.AddParagraph("Due date: {{dueDate}}");
builder.Save();
```

**Operation:** Detect variables
```csharp
using var detector = DocumentBuilder.Open("03-detection-template.docx");
var variables = detector.DetectVariables();
// Returns:
// [ { Name: "customerName", FullMatch: "{{customerName}}", Location: "paragraph" },
//   { Name: "orderNumber",  FullMatch: "{{orderNumber}}",  Location: "paragraph" },
//   { Name: "totalAmount",  FullMatch: "{{totalAmount}}",  Location: "paragraph" },
//   { Name: "dueDate",      FullMatch: "{{dueDate}}",      Location: "paragraph" } ]
```

**Output:** `output/docx/03-detection-template.docx` (unchanged)

Console:
```
Found 4 variables:
  - customerName
  - orderNumber
  - totalAmount
  - dueDate
```

## 4. Mail Merge (Variable Replacement)

**Input:** Template with variables

```csharp
// 04-merge-template.docx contains:
// Hello {{name}}!
// Your order details:
// Order #: {{orderNumber}}
// Total: ${{total}}
// Status: {{status}}
```

**Operation:** Replace variables with data
```csharp
using var builder = DocumentBuilder.Open("04-merge-template.docx");
builder.MergeVariables(new Dictionary<string, string>
{
    ["name"] = "Alice",
    ["orderNumber"] = "ORD-2024-001",
    ["total"] = "299.99",
    ["status"] = "Shipped"
});
builder.Save("04-merge-result.docx");
```

**Output:** `output/docx/04-merge-result.docx`

```
Hello Alice!
Your order details:
Order #: ORD-2024-001
Total: $299.99
Status: Shipped
```

> **Note:** The original template `04-merge-template.docx` is preserved.

## 5. JSON Instructions

**Input:** `instructions/sample.json`

```json
{
  "version": "1.0",
  "operations": [
    {
      "type": "AddParagraph",
      "content": "This paragraph was added via JSON instructions.",
      "style": "Normal"
    },
    {
      "type": "AddHeading",
      "content": "Section Added by Instructions",
      "level": 2
    },
    {
      "type": "AddBulletList",
      "items": [
        "First bullet point",
        "Second bullet point",
        "Third bullet point"
      ]
    },
    {
      "type": "Replace",
      "target": "{{companyName}}",
      "content": "Acme Corporation"
    },
    {
      "type": "AddTable",
      "headers": ["Item", "Quantity", "Price"],
      "rows": [
        ["Widget", "10", "$25.00"],
        ["Gadget", "5", "$50.00"],
        ["Tool", "3", "$75.00"]
      ]
    }
  ]
}
```

**Operation:** Parse and execute instructions
```csharp
var parser = new DocxJsonInstructionParser();
var instructions = parser.Parse(File.ReadAllText("sample.json"));
var engine = new InstructionEngine();
engine.Execute(document, instructions);
```

**Output:** Document modified according to the instruction set.
