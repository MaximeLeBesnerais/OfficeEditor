# XLSX Examples

This folder contains examples for creating and editing Excel workbooks (.xlsx).

## Examples

### 1. Basic Workbook Creation
Create a workbook with worksheets, headers, and data.

### 2. Formulas and Calculations
Use Excel formulas for automatic calculations.

### 3. Multiple Worksheets
Create workbooks with multiple sheets and cross-references.

### 4. Variable Detection
Find `{{variables}}` in spreadsheet cells.

### 5. Template Processing
Use conditionals and loops in spreadsheet templates.

## Running Examples

```bash
cd examples/Xlsx
dotnet run
```

Output files are saved to `examples/output/xlsx/`.
