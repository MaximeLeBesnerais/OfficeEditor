What was confirmed

Global connector loss is four separate bugs

Regular connectors: p:cxnSp with prst="line" falls into a filled-rectangle fallback instead of rendering its stroke. This explains France slide 3.

SmartArt custom connectors: SmartArt shapes with custGeom but no prstGeom return null from geometry reading and disappear. This explains SmartArt slides 83 and 105.

Unsupported connector variants: prst="none" and unknown presets are silently skipped.

Color-resolution interaction: some connector/arrow groups collapse to monochrome through ColorsDef resolution, notably SmartArt slide 143.

Color and effect gaps

Chart fills drop transforms; shadows drop lum/tint chains; GradientFillReader misses hue/saturation/luminance/alpha offsets; style and gradient color transforms are inconsistent; some SmartArt solid fills ignore saturation modifiers.

Text gap

The decorative - 05 - string is incorrectly treated as a bullet marker by SourceGeneration, consuming its first dash. Text rotation for slides 115/117/118 needs further visual verification; the rotation precedence itself was not proven wrong, but rotated no-wrap sizing and anchor inheritance remain suspects.
